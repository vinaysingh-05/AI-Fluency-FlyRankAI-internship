

## About

A minimal, self-contained landing page marking the first live milestone of the portfolio. Built with a dark-mode Slate/Zinc palette, a subtle emerald accent, and a terminal-style status card as its signature visual element.

## Tech Stack

- HTML5
- Plain CSS (hand-written, no framework dependency)
- Zero build tools, zero external requests

> Note: an earlier version used the Tailwind CSS CDN script for speed. It was replaced with hand-written CSS to remove the "do not use in production" console warning and drop the external dependency entirely.

## Features

- Fully responsive (mobile → desktop)
- Pulsing live-status badge
- Terminal-style milestone note
- Ambient background animation, disabled automatically under `prefers-reduced-motion`
- Single `index.html` file — no dependencies, no setup required

## Getting Started

Clone the repo and open the file directly in a browser:

```bash
git clone https://github.com/<your-username>/vinay-portfolio.git
cd vinay-portfolio
open index.html   # or just double-click it
```

No install step, no package manager, no build process.
