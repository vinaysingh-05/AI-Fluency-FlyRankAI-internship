# 🎨 Personal Brand Identity Kit

A clean, modern, and professional visual identity designed for my AI & Machine Learning portfolio. This identity kit establishes a consistent design language that will be used across all portfolio pages, project case studies, and future personal branding materials.

---

## 📌 Project Overview

This Brand Identity Kit defines the core visual elements of my personal portfolio, ensuring consistency, readability, and a professional user experience.

The design follows a minimal and technology-focused approach, allowing projects and content to remain the primary focus.

---

## ✨ Components

### 📝 Typography

| Usage | Font |
|-------|------|
| Headings | Poppins Bold |
| Body Text | Inter Regular |

Both fonts are free Google Fonts selected for their modern appearance and excellent readability.

---

### 🎨 Color Palette

| Purpose | Hex Code |
|----------|-----------|
| Primary | `#2563EB` |
| Text | `#111827` |
| Background | `#F9FAFB` |
| Accent | `#10B981` |

The palette is intentionally limited to maintain a clean and consistent visual identity.

---

### 🔷 Logo / Favicon

A minimalist **VK** monogram represents my personal brand.

Design Principles:
- Flat Design
- No Gradients
- No Shadows
- Scalable
- Works as a Website Favicon
- Suitable for Portfolio, GitHub, and Social Profiles

---

## 🎯 Design Philosophy

The identity is built around three core principles:

- Simplicity
- Consistency
- Professionalism

Every design decision is intended to support the portfolio's content rather than distract from it.
